ENTITIES (target_type)

1. person — a human individual
   - occupation: one or more roles/professions (e.g. "physicist", "novelist", "musician")
   - domain: broad field of activity ("music", "science", "literature", "politics", "sports", ...)

2. event — a historical or scheduled occurrence

3. work — a created output (book, song, film, paper, building, invention, discovery, theory, patent, etc.)

FIELD-TO-FILTER MAPPING (stage1 JSON output)
- filters.occupation: only meaningful when target_type = "person"
- filters.location: person -> birthplace/nationality; event -> where it happened; work -> place of origin
- filters.domain: applies to any target_type. Use the most specific field/subject/category mentioned

- filters.time_constraint:

    - event -> start_year / end_year

    - type "in_range": absolute year/decade/century window
    - type "relative_to_entity": timeframe defined relative to exactly ONE fixed named entity mentioned

      "composers before Beethoven" (find all such composers). Not resolved to a date.

      (so "the 1940s" = 1940-1949)

      using one as a fixed anchor, leave this null and use filters.compare_entities instead.
- filters.related_entity: use when the sentence identifies the target by its relationship to a specific

  event, "located_in" for a specific named place). Do not use this for relationships expressed purely

  work/event/place — do not paraphrase or normalize it (e.g. keep "Symphony number 5" as written,
  don't rewrite it to "Symphony No. 5"). If the sentence gives no specific named entity, this field is
  null, even if occupation/domain/location filters are present.
- filters.compare_entities: use when the sentence directly compares two or more SPECIFIC NAMED entities

  Pick aspect based on what property is being compared, using only the attributes the knowledge base

    - aspect "age": relation is more/fewer/equal, comparing how long each named person lived (derived
      from birth_year/death_year) — e.g. "Who lived longer, X or Y?", "Did X die younger than Y?"
      Only applies to target_type "person".
    - aspect "location": relation is same/different, comparing where each named entity is tied to
      (birthplace for person, event location, work's place of origin) — e.g. "Were X and Y born in
      the same country?", "Did these two wars happen in the same place?"
